## 🚀 Key Features

- **MIDI Key Editor** — Precisely edit MIDI notes, velocities and articulations.
- **VariAudio** — Adjust pitch and timing of monophonic vocal recordings.
- **MixConsole** — Balance tracks using channel processing, buses and effects.
- **Audio Alignment** — Tighten timing relationships between recorded performances.
- **Score Editor** — Work with musical notation alongside MIDI arrangements.
- **Control Room** — Manage monitoring and listening setups during production.
